# 📚 HTML Marquee Demo

A simple and interactive web application developed using **HTML5** to demonstrate the functionality of the HTML `<marquee>` element. This project showcases different scrolling effects for text and images, providing a practical understanding of basic web animation techniques and HTML attributes.

---

## 📖 Overview

The **HTML Marquee Demo** is designed as an educational project for Web Technology learners. It demonstrates how marquee elements can be used to create animated scrolling content in multiple directions. The project includes scrolling text, animated images, hover effects, and different marquee behaviors, making it an excellent learning resource for beginners.

---

## ✨ Features

- Horizontal scrolling text
- Alternate (bouncing) text animation
- Upward scrolling images
- Horizontal scrolling images
- Pause scrolling on mouse hover
- Clean and user-friendly interface
- Beginner-friendly HTML implementation

---

## 🛠️ Technologies Used

- **HTML5**
- **Basic CSS**
- **Marquee HTML Element**
